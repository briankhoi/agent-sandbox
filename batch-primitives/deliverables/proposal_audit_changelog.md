## 3. Implementation-Only Minutiae and Non-Design Clutter Stripped

Per design-doc hygiene rules, neither Version A nor Version B exposes internal private SDK classes, private attributes, lock ordering, or model-checking tooling. In addition, Version B (`batch_claim_proposal_restructured.md`) underwent a focused design-purity and readability pass to strip post-implementation benchmark dumps and low-level plumbing mechanics so it reads strictly as a clean SDK design document.

1. **Private helper classes and functions (omitted in both A & B):** `_BatchState`, `_WarmPoolCredit`, `_UnretriedApiClient`, `_api_client_without_retries`, `_take_batch_lease`, `_renew_once`, `_write_renewal`, `_watch_loop`, `_create_one`, `_delete_claims_in_rounds`, `_delete_batch_objects`, `_claim_list_pages`, `_precheck_pools`, `_check_pool`, `BatchWatchdog._poll_once`, and `forget_claim_in_client`.
2. **Internal synchronization and wire workarounds (omitted in both A & B):** `_lock`, `_lifecycle_lock`, `_changed`, `_acquire_waiters`, `_checking_acquires`, `_checked_pools`, `_active_deletes`, `_no_active_deletes`, `_stop_creating`, `_seeded_pod_ip`, `_closing_batches`, internal mutex acquisition order, `MicroTime` `isoformat()` microsecond workarounds, and `kubernetes<36` `BearerToken` aliasing.
3. **Formal verification tool names (omitted in both A & B):** Neither version mentions formal specification languages or model checkers; both explain Lease-UID claim selector fencing (`agents.x-k8s.io/batch-lease-uid`), monotonic holder self-fencing, and the full `leaseDurationSeconds` reaper confirmation wait directly through concrete multi-process race scenarios and Kubernetes `Lease` / `ownerReferences` invariants.
4. **Downstream RL results, benchmark campaigns, and low-level plumbing (stripped from Version B):**
   - Removed `examples/agent-sandbox-rl` integration internals (`SandboxFleet`, `BatchClaimConfig`, `BatchWatchdog`, snapshot annotations) and all post-implementation `kind` / GKE Campaign 2 benchmark tables (`R2E-Gym`, `SWE-bench Verified`, `T0`/`T1` boot-disk sweeps, `10,000`-claim soak metrics, `Config H` controller flags, APF share manifests, and `DaemonSet` SSD hydration rules).
   - Removed validation regexes and string-encoding recipes (`^[a-z]([-a-z0-9]*[a-z0-9])?$`, `<= 52` character arithmetic, `"b"` + 11 random chars, `<host>_<pid>_<8hex>`, `sha256(warmpool)[:16]`, `6` significant digits).
   - Removed HTTP transport, connection-pool, retry, and paging plumbing (`pool_size: int | None = None`, `max_in_flight + 2` clamping rules, `urllib3` `Retry(3)` / `retries=False`, Go `QPS = -1` and `x/net/http2` socket receive buffers, `500`-item page constants, `managedFields` stripping, raw `deletecollection` chunk draining, `[5s, 30s]` `Retry-After` clamping, `1s` refresh timers, exhaustive controller reason string lists, and hardcoded `- 5s` / `+ 600s` arithmetic).
